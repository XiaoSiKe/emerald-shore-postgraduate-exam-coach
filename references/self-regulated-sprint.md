# 自我调节冲刺：计划—监控—反思

用于学生知道目标却难以持续执行、计划频繁失真，或需要周复盘时。核心不是监督学生服从，而是让他逐步能自己计划、监控和纠偏。

## 1. 计划：把结果目标变成过程目标

-  高层结果可以是目标总分，但本周目标必须是可控制行为，例如“完成两次 90 分钟数学限时训练并登记全部错因”。
- 目标必须具体、接近、能验收；“努力复习英语”不合格。
- 先选策略和证据，再排时间。计划中没有闭卷、限时或作品证据，就不是训练计划。

## 2. 启动：使用 if–then 协议

当学生反复拖延时，调用 `focus`：

- `if` 是可观察情境：具体时间/事件和地点，不能是“有动力时”。
- `then` 是小到能立即开始的动作：打开指定任务并做 5 分钟闭卷启动。
- 为最可能的内部障碍写一个应对计划；失败时缩到 2 分钟，而不是取消。

大学生日常优先使用已经存在的生活锚点，例如“上午最后一节课结束后到食堂”“晚饭后进入图书馆”“实验结束回宿舍前”。若 `routine set` 已保存常用地点，`focus` 可以直接复用；但时间或事件仍必须具体。

if–then 不是万能意志力。若任务本身超量、睡眠不足或策略错误，先调整条件。

## 3. 执行监控：只看少量信号

训练中只监控：是否按触发开始、是否产生完成证据、实际分钟、首个关键错因。不要让记录本身占用学习时间。需要帮助时说清“我卡在什么、试过什么、观察到什么”。

## 4. 反思：聚焦策略，不归因人格

每周调用 `weekly`，按顺序回答：

1. 计划行为发生了多少次？
2. 有多少次产生闭卷/限时证据？
3. 重复出现的错因是什么？
4. 哪个策略有效，哪个条件失真？
5. 下周保留、删除、调整什么？

先调用 `efficiency` 展示多维证据，再让学生先说自己看到的模式。教练随后补充分析，并把“下周目标”写成一个学习策略目标，例如“每次专业课训练先闭卷解释原理，再做无提示题”，而不是只有“多学两小时”。

“我不自律”“我不聪明”不是可操作解释。改写成可验证的策略或环境原因。

## 5. 支架递减

开始阶段由 Skill 提供完整日计划、启动句和检查点；连续两周稳定执行后，只保留周主攻和自选任务；能够独立复盘后，Skill 只在成绩、范围或执行率显著变化时介入。目标是增强学生自主性，不制造对教练的永久依赖。

## 证据边界

此模块依据 Zimmerman 的自我调节学习循环、Panadero 对 SRL 模型的综述，以及 Gollwitzer 的 implementation intentions 研究原创转译。它们支持计划、监控、反思和 if–then 行动链接，但不保证对每个人产生相同幅度的效果；必须用实际执行和考试证据校准。
