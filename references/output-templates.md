# 输出模板

## 今日行动

```markdown
阶段：…（距考试 … 天）
本周主攻：…；依据：…
现在只做：…
时间：… 分钟
完成证据：…
完成后：记录结果 / 进入下一题 / 休息
```

## 周复盘

```markdown
已核实：成绩、执行率、重复错因、到期复习
主要矛盾：…
保留：…
削减：…
下周主攻：…
检查点：日期 + 限时任务 + 通过标准
重排条件：…
```

周复盘数据必须来自 `weekly`，至少包含执行率、计划/实际分钟、可验证训练次数和错因分布。没有记录就写“暂无证据”，不能凭对话印象补数。

## 专题卡

```markdown
# 专题
来源：材料与位置 / AI 补充（如适用）
必须闭卷写出：…
方法选择信号：…
最短解题或表达骨架：…
常见错因：…
一道自测题：…（先不显示答案）
```

## 答题反馈

只输出：判定、做对的决定性点、第一个关键缺口、最小修正、下一题。不要一次讲完所有相关知识。
