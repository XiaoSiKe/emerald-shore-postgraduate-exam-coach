# 输出模板

## 今日行动

```markdown
阶段：…（距考试 … 天）
今天类型：工作日 / 周末；现实容量：… 分钟
固定安排：…；地点锚点：…；睡眠底线：…
本周主攻：…；依据：…
现在只做：…
时间：… 分钟
完成证据：…
完成后：记录结果 / 进入下一题 / 休息
```

## 周复盘

```markdown
已核实：成绩、执行率、重复错因、到期复习
主要矛盾：…
保留：…
削减：…
下周主攻：…
检查点：日期 + 限时任务 + 通过标准
重排条件：…
```

周复盘数据必须来自 `weekly`，至少包含执行率、计划/实际分钟、可验证训练次数和错因分布。没有记录就写“暂无证据”，不能凭对话印象补数。

## 专题卡

```markdown
# 科目 / 章节 / 专题
来源：材料与位置；证据等级；归类置信度；匹配依据（如适用）
必须闭卷写出：…
方法选择信号：…
最短解题或表达骨架：…
常见错因：…
一道自测题：…（先不显示答案）
```

专题卡必须能让学生直接开始背、做或自测；纯目录只负责导航，不能替代内容卡。

## 课程骨架

```markdown
科目：…；科目代码：…；目标院校：…
范围依据：官方 / 真题 / 用户材料 / 目标院校公开资料 / 外部讲解
章节 → 专题 → 当前证据 → 优先级
待确认材料：…
当前只稳定的主攻专题：…
```

骨架只收录能回链到来源的范围与权重判断。目标院校公开资料必须附匹配说明；低置信内容放在待确认区。

## 答题反馈

只输出：判定、做对的决定性点、第一个关键缺口、最小修正、下一题。不要一次讲完所有相关知识。

## 效率评估

```markdown
评估窗口：最近 … 天
执行：…
有效证据：…
独立答题：…
重复错因：…
检查点变化：…
当前最上游漏点：…
现在只改：…
```

不要输出综合效率分。先让学生解释数据，再补充分析。

## 通俗讲解

```markdown
一句话本质：…
生活类比：…
类比到这里为止：…
考试里怎么用：…
现在请你用自己的话讲回去：…
```

普通场景最多一处轻量幽默；去掉幽默后，结论、证据和下一动作仍必须完整。
