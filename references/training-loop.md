# 训练闭环与材料规则

## 材料建库

调用 `ingest --subject` 时明确科目和证据等级；只有范围或题型证据明确时才绑定 `--topic`：

- `official`：当年官方大纲、招生简章或官方考试说明；必须核实来源。
- `past_paper`：能确认年份和考试身份的真题、样题或官方模拟题。
- `target_school_open`：与目标院校及科目/代码明确匹配的公开资料；必须用 `--match-note` 记录材料类型、年份和匹配依据，不能冒充官方范围。
- `user_material`：用户教材、课程、笔记、题库和错题。
- `external_aid`：用于解释的公开资料，不决定考试范围。

同一结论冲突时按“官方范围 → 用户确认的指定材料/真题 → 匹配清楚的目标院校公开资料 → 其他用户材料 → 外部讲解”处理，并展示冲突。文件名本身不能证明材料是官方、真题或目标院校资料。

同时记录 `high` / `medium` / `low` 归类置信度：低置信材料保持未绑定；中等置信材料只能暂归科目，不能绑定具体专题；只有高置信材料才能作为专题训练入口。详细规则见 [课程骨架与证据系统](course-evidence-system.md)。

PDF 无文字时不要猜。报告扫描件限制，使用宿主视觉/OCR 时让用户知道结果需要核对；未经允许不上传资料到外部服务。

## 一次一题

1. 优先调用 `drill --subject [--topic]` 选择来源题；它会优先到期题和历史错题。
2. 只展示返回的 `question` 和 `source`，不展示答案、关键词或暗示性评分点。
3. 等待学生作答。
4. 判定正确、基本正确、部分正确或需重做；先指出决定性一步。
5. 记录错因。只补最小解释，然后要求修订或给一题近迁移。
6. 调用 `attempt` 记录逐题结果；今日任务用 `log`，正式限时测试用 `checkpoint`。

连续错两次时缩小步长，不重复原解释。先查是概念、识别、推理、步骤、粗心还是时间问题。连续三次 `wrong`/`partial` 时停止加题，回到专题卡完成最小重建和一次闭卷复述，再用替代题重测。

## 来源诚实

- 没有来源答案时，不把模型答案称为标准答案。
- 只有解答、没有完整题干时，明确缺失，不重构成“原题”。
- 外部资料只能帮助理解，不能因为主题相似就变成目标院校考点。
- “可能高频”必须有真题分布、官方说明或教师材料；否则改称“待验证”。
- 目标院校公开仓库只能增强题型线索；院校、科目代码、材料类型或年份不匹配时，降为 `external_aid`。

## 每日循环

先调用 `today`。按顺序完成到期回忆、主攻训练、维持训练；每项都要有闭卷或限时证据。结束时记录实际分钟、结果和错因。若任务总量明显不现实，运行 `replan`，不靠熬夜补齐虚假的计划。
