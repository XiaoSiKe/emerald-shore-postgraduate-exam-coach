# PRD：青岸计划·考研冲刺教练 V0.1.0

## 问题

冲刺阶段的大学生通常同时面对范围大、科目多、时间估算失真、被动学习、错题不回流和焦虑拖延。普通学习计划容易平均分配、排得过满，并在第一次失约后失去价值。

## 用户与任务

主要用户是距离考研初试约 1–4 个月、需要在多科之间取舍的大学生。他们需要持续知道：当前最重要的问题是什么，今天做哪几件事，如何证明学会，什么结果会改变计划。

## 产品承诺

- 依据真实分数、考试权重、错因和可用时间确定主攻方向。
- 每天最多三个关键任务并预留缓冲。
- 用闭卷回忆、限时题和输出结果代替熟悉感。
- 保留材料来源，拒绝无证据押题。
- 执行率或成绩变化后重排，而不是维护失真的旧计划。
- 情绪支持落到现实可启动的下一步。

## 非目标

- 不提供目标院校录取保证、分数保证或押题率。
- 不内置某一科目的完整课程内容。
- 不替代官方招生信息、教师、医生或心理咨询。
- 不上传、分享或遥测用户学习资料。

## 核心旅程

1. 用户提交日期、可用时间、科目分值、当前成绩和目标。
2. Skill 初始化本地状态并选择冲刺阶段。
3. 用户可导入材料；系统生成来源记录和可检索文本。
4. 系统确定一个周主攻并生成不超容量的今日任务。
5. 用户完成闭卷或限时训练，记录时间、结果和错因。
6. 到期复习、检查点成绩和执行率进入下一轮计划。
7. 用户始终得到一个明确下一动作和可观察完成信号。

## 成功指标

V0.1.0 不收集遥测。通过本地测试和用户自愿反馈观察：成功初始化率、今日任务生成率、任务记录率、周检查点完成率、错误重现下降、计划重排后执行率，以及虚构来源/押题投诉为零。

## 验收

四门不同类型科目可进入同一工作区；任务分钟不超过扣除缓冲后的容量；重复计划不生成重复 ID；错误会进入错题和次日复习；检查点改变当前分并重排；无文字 PDF 提示视觉/OCR 降级；所有失败返回可恢复 JSON。
